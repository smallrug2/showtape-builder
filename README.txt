Showtape Builder + Rechannel Tool (showtape_builder.py)

WHAT IT DOES:
Builds animatronic-style showtape audio + data files from a lines file (with --demo mode) and re-channels tapes from charts.

REQUIREMENTS:
Python 3.8+ only - no extra packages needed (stdlib only).

HOW TO RUN:
python showtape_builder.py --help
python showtape_builder.py build --demo

PLATFORM:
Windows + Linux + Mac: yes.
